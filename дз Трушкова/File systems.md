Пункт 6:
procfs - виртуальная файловая система, предоставляющая доступ к информации о процессах и состоянии ядра в виде файлов.
cifs - сетевая файловая система для доступа к общим папкам. обычно монтируется вручную
tmpfs - виртуальная файловая система, размещаемая в оперативной памяти и используемая для временных файлов, что обеспечивает очень высокую скорость доступа
sysfs - виртуальная файловая система, предоставляющая единообразный интерфейс для получения информации об устройствах, драйверах и некоторых компонентов ядра

Задание 4:

Пункт 1:
raid - технология объединения нескольких дисков в один логический элемент для повышения производительности и/или надежности

raid 0 - данные разбиваются на блоки и пишутся на оба диска одновременно
raid 1 - данные полностью дублируются на два диска
raid 5 - данные и контрольные суммы распределяются по всем дискам
raid 10 - комбинация raid 0 и raid 1

Пункт 2:
sudo fdisk /dev/sdc
sudo mkfs.ext4 /dev/sdc1
sudo fdisk /dev/sdd
sudo mkfs.ext4 /dev/sdd1
lsblk

Пункт 3:
создаем raid0:
sudo mdadm --create /dev/md0 --level=0 --raid-devices=2 /dev/sdc1 /dev/sdd1

проверяем:
cat /proc/mdstat
sudo mdadm --detail /dev/md0

создаем фс на raid
sudo mkfs.ect4 /dev/md0

монтируем и тестим:
sudo mkdir /mnt/raid0
sudo mount /dev/md0 /mnt/raid0
sudo touch /mnt/raid0/test_file_raid.txt
ls -la /mnt/raid0/

Пункт 4:
проверяем, измеряя скорость
cat /proc/mdstat
sudo mdadm --detail /dev/md0
sudo dd if=/dev/zero of=/mnt/raid0/test.bin bs=1M count=100

Пункт 5:
удаляем raid0
sudo umoun /mnt/raid0
sudo mdadm --stop /dev/md0

создаем raid1 и проверяем
sudo mdadm --create /dev/md1 --level=1 --raid-devices=2 /dev/sdc1 /dev/sdd1
cat /proc/mdstat
sudo mdadm --detail /dev/md1

монтируем

sudo mkdir /mnt/raid1
sudo mount /dev/md1 /mnt/raid1
sudo touch /mnt/raid1/test_file_raid1.txt
